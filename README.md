# TURBODROP | АВТО — Telegram Mini App

Готовый статический проект для GitHub Pages и Telegram Mini App: 100 реальных моделей, 10 новых тематических кейсов, детали вместо денежной прокачки, 5 игр, доход гаража и сохранение прогресса.

## Загрузка на GitHub

1. Распакуйте архив.
2. Откройте репозиторий → **Add file → Upload files** и перетащите все файлы из корня архива.
3. Нажмите **Commit changes**. Одноимённые файлы заменятся автоматически.
4. Дождитесь публикации GitHub Pages, полностью закройте и снова откройте Mini App.
5. Проверка: **Меню → Версия 5.0 · картинки машин: ✅ все 100**.

Сборка, npm и сервер не нужны. Адрес Mini App в BotFather остаётся прежним: `https://yuriastreyko-lab.github.io/turbodrop/`.

## Сброс прогресса

В версии 5.0 используется новый ключ сохранения `tdrop5reset`. Старые данные `tdrop1` больше не загружаются, поэтому после публикации все игроки начинают заново с 1,5 млн ₽. Это одноразовый откат именно для этого обновления; дальше текущий прогресс сохраняется как обычно.

Прогресс хранится локально в браузере и, при доступности, в Telegram CloudStorage. Отдельного сервера и общей базы игроков у проекта нет.

## Экономика и кейсы

- Доход машины: **3,5% её игровой цены в час**.
- Накопление без сбора: **максимум 4 часа**.
- Продажа машины: **18% её цены**.
- Три и более машины одной страны: **+10% к их доходу**.
- Старт: 10 мест в гараже; максимум 40.

## Детали вместо прокачки

Детали выпадают из любого кейса вместе с машиной: минимум одна за открытие, с шансом 20% — дополнительная. Есть 8 типов: двигатель, турбина, КПП, выхлоп, подвеска, диски и шины, тормоза, обвес.

У каждой машины 8 слотов. Установка не стоит денег, но расходует деталь со склада. Каждая установленная деталь даёт **+6% мощности и +4% дохода**. Полный комплект добавляет ещё **+12% мощности и +18% дохода**. При продаже машины установленные детали возвращаются на склад.

## Игры и ставки

- **Гонка** — реакция на зелёный сигнал, фальстарт и приз по сложности.
- **Колесо** — прежнее поведение: ручная сумма, половина баланса и весь баланс доступны.
- **Пит-стоп** — четыре колеса и ускоряющийся ползунок.
- **Аукцион** — угадывание изменения цены и растущий банк.
- **Ралли** — **30 секунд**, максимальная выплата **×1,5**. Первые 8 секунд выплаты нет, затем она постепенно растёт. Скорость камней и частота парных препятствий увеличиваются со временем.

В гонке, пит-стопе, аукционе и ралли доступны только фиксированные ставки от 100 тыс. до **5 млн ₽**. Ручного ввода, «½ баланса» и «Весь баланс» там нет.

## Файлы

- `index.html` — точка входа;
- `style.css` — оформление для телефона и компьютера;
- `game.js` — автомобили, кейсы, детали, экономика и игры;
- `images.js` — 100 встроенных WebP-изображений 800×333;
- `Список автомобилей.md` — отдельный список всех моделей;
- `CREDITS.md` — примечание по изображениям.

Если изображение не загрузилось, включается запасной SVG-автомобиль. Собственные ссылки можно указать в `CAR_URLS` в `game.js`; они имеют приоритет над встроенными изображениями.
