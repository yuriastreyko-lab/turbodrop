# TURBODROP | АВТО: Telegram Mini App
Гараж с пассивным доходом, кейсы с машинами, уровни и задания, гонки на реакцию (старт против робота, фальстарт).

## Запуск
1. Создай публичный репозиторий (например `turbodrop`) и загрузи `index.html`, `style.css`, `game.js` (и `photos.js`, если он у тебя есть).
2. Settings → Pages → Deploy from a branch → `main` / root. Через 1–2 минуты адрес появится вверху страницы Pages.
3. @BotFather → /mybots → твой бот → Bot Settings → Menu Button → Configure menu button → вставь адрес `https://ЛОГИН.github.io/turbodrop/`.

## Настройка
В начале `game.js` (блок «ДАННЫЕ») меняются машины, кейсы и шансы выпадения, сложность гонок, награды, ежедневные задания и доход гаража. Новая машина: одна строка `Название|редкость|л.с.|цена в млн|страна|цвет`.

## Ограничения
Прогресс хранится на устройстве игрока. Рейтинг, друзья и обмен между игроками требуют сервера и базы данных.

## Кейсы
8 кейсов: Старт, СССР, Внедорожники, Дрифт, Маслкары, Спорткары, Редкие, Легенды. У каждой машины в `game.js` есть теги тем (последнее поле строки, через запятую), у кейса поле `t` выбирает тему. Чтобы добавить машину в кейс, допиши ей тег. Чтобы сделать новый кейс, добавь строку в `CASES` с новой темой `t`.
