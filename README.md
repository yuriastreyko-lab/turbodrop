# TURBODROP | АВТО: Telegram Mini App
Гараж с пассивным доходом, кейсы с машинами, уровни и задания, гонки на реакцию (старт против робота, фальстарт).

## Запуск
1. Создай публичный репозиторий (например `turbodrop`) и загрузи `index.html`, `style.css`, `game.js` (и `photos.js`, если он у тебя есть).
2. Settings → Pages → Deploy from a branch → `main` / root. Через 1–2 минуты адрес появится вверху страницы Pages.
3. @BotFather → /mybots → твой бот → Bot Settings → Menu Button → Configure menu button → вставь адрес `https://ЛОГИН.github.io/turbodrop/`.

## Настройка
В начале `game.js` (блок «ДАННЫЕ») меняются машины, кейсы и шансы выпадения, сложность гонок, награды, ежедневные задания и доход гаража. Новая машина: одна строка `Название|редкость|л.с.|цена в млн|страна|цвет`.

## Ограничения
Прогресс хранится на устройстве игрока. Рейтинг, друзья и обмен между игроками требуют сервера и базы данных.

## Кейсы
8 кейсов: Старт, СССР, Внедорожники, Дрифт, Маслкары, Спорткары, Редкие, Легенды. У каждой машины в `game.js` есть теги тем (последнее поле строки, через запятую), у кейса поле `t` выбирает тему. Чтобы добавить машину в кейс, допиши ей тег. Чтобы сделать новый кейс, добавь строку в `CASES` с новой темой `t`.

## Игры
Раздел «Игры»: сверху выбор машины и прокачка (до 5 уровня, +10% мощности за уровень), ниже игры. Каждая игра берёт взнос.
- **Гонка**: старт против робота. Взнос и приз в `DIFF` в `game.js`.
- **Колесо**: стрелка крутится, зелёно-красная дуга внизу это шанс выигрыша. Чем больше шанс, тем дуга шире, 50% это бока, 100% верх. Множитель считается от шанса, комиссия падает у мощных машин (`edgeOf`).
- Заготовки на будущее: Пит-стоп, Аукцион, Ралли (карточки «Скоро» в `SOON`). Новую игру добавляй как ещё одну ветку в `V.games`.

## Картинки машин
Положи файлы в папку `cars/`, имя файла = номер машины из `cars/СПИСОК.txt` + `.png` (например `1.png`).
Формат: PNG с прозрачным фоном, вид сбоку, машина смотрит вправо, 960x400 px, до 150 КБ. Если файла нет, показывается нарисованная машина.
Через `photos.js` тоже можно: `PHOTOS = { 'Название машины': 'ссылка' }`, он в приоритете над папкой.

## Промокоды
Раздел «Игры» → внизу поле «Промокод». В `game.js` в объекте `PROMO` лежат не сами коды, а хэши (чтобы их нельзя было подсмотреть в репозитории). Каждый код работает один раз на устройство.
Чтобы сделать новый код, открой любую страницу в браузере, нажми F12 → Console, вставь строку (замени МОЙКОД) и скопируй результат:
`(async c=>[...new Uint8Array(await crypto.subtle.digest('SHA-256',new TextEncoder().encode('tdrop:'+c)))].map(x=>x.toString(16).padStart(2,'0')).join(''))('МОЙКОД')`
Потом добавь в `PROMO` строку `'ХЭШ':СУММА,`. Код вводится заглавными, пробелы игнорируются.
