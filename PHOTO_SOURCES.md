# Фотографии автомобилей

Проект запрашивает фотографии моделей автомобилей из Wikimedia Commons через открытый API и использует только результаты, у которых в метаданных указана лицензия CC BY, CC BY-SA, CC0 или Public Domain. Фотографии загружаются при открытии экранов; отдельная папка `cars` не нужна.

Важно: поиск автоматический, поэтому результат для конкретной модели нужно проверить визуально. Лицензии CC BY/CC BY-SA могут требовать указания автора, ссылки на источник и лицензии. Для публикации проверь карточку изображения на Wikimedia Commons. Если фото не удалось получить (нет сети, CORS/сервер недоступен или не найдено подходящее изображение), игра показывает векторную заглушку.

Фотографии не встраиваются в архив и загружаются из интернета при использовании игры.
