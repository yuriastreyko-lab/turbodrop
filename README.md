# TURBODROP | АВТО — Telegram Mini App

Гараж с доходом, 8 тематических кейсов (56 машин), прокачка, 5 игр, промокоды, сохранение прогресса.

## Файлы (всё лежит в корне репозитория, папок нет)
- `index.html` — страница
- `style.css` — оформление (телефон и компьютер)
- `game.js` — вся игра: цены, шансы, игры, промокоды (блоки с настройками в начале файла)
- `images.js` — 56 картинок машин, встроенные в один файл
- `README.md` — эта инструкция

## Как обновить сайт на GitHub
1. Распакуй архив.
2. Открой репозиторий → **Add file → Upload files** → перетащи все 5 файлов → **Commit changes**. Одноимённые файлы заменятся сами.
3. Старые `photos.js` и папку `cars` можно удалить (они больше не нужны).
4. Подожди 1–2 минуты (вкладка Actions — зелёная галочка), полностью закрой и снова открой бота.
5. Проверка: Меню → строка «Версия 4.0 · картинки машин: ✅ все 56».

## Игры (раздел «Игры»)
Сверху выбирается машина и прокачивается (до 5 уровня, +10% мощности за уровень). Каждая игра берёт взнос.
- **Гонка** — старт против робота, фальстарт, реакция.
- **Колесо** — сам выбираешь шанс; чем больше шанс, тем шире дуга.
- **Пит-стоп** — 4 колеса, нужно остановить ползунок в зелёной зоне.
- **Аукцион** — угадай, цена выше или ниже; банк растёт с каждым верным ответом.
- **Ралли** — 20 секунд уворачиваешься от камней.

## Кейсы
Старт 200 тыс · СССР 500 тыс · Внедорожники 1,3 млн · Дрифт 2,4 млн · Маслкары 2,5 млн · Спорткары 4,3 млн · Редкие 7,5 млн · Легенды 15 млн.
Цены — `c:` в блоке `CASES`; цена продажи машины — `SELL` (сейчас 26%: так деньги не размножаются).

## Промокоды
Поле внизу раздела «Игры». В `game.js` в `PROMO` лежат хэши, а не коды. Каждый код работает один раз на устройство.
Новый код: открой любую страницу в браузере, F12 → Console, вставь строку (замени МОЙКОД), скопируй результат и добавь в `PROMO` строку `'ХЭШ':СУММА,`
`(async c=>[...new Uint8Array(await crypto.subtle.digest('SHA-256',new TextEncoder().encode('tdrop:'+c)))].map(x=>x.toString(16).padStart(2,'0')).join(''))('МОЙКОД')`

## Картинки машин
Лежат в `images.js` (WebP, номера как в списке `CARS` в `game.js`). Если картинка не загрузилась, машина рисуется кодом.
Свои ссылки: в `game.js` в объект `CAR_URLS` впиши `'Название машины':'https://…'`, они в приоритете.

## Сохранение
Прогресс хранится в браузере (localStorage) и дополнительно в облаке Telegram, поэтому переносится между устройствами внутри Telegram.
